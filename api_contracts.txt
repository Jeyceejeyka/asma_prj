POST /api/v1/accounts/refresh/

**Headers:**
- Content-Type: application/json

**Authentication:** None

Request JSON:
```json
{
  "refresh": "jwt-refresh-token-string"
}
```

Success Response (200):
```json
{
  "access": "jwt-access-token-string"
}
```

Error Response (401):
```json
{
  "detail": "Token is invalid or expired."
}
```

**Field Explanations:**
- `refresh`: JWT refresh token
- `access`: New JWT access token

Validation Rules:
- Refresh token must be valid and not expired

POST /api/v1/cart/checkout/

**Headers:**
- `Authorization: Bearer <token>` (required)
- `Idempotency-Key: <unique-string>` (required)

**Authentication:** Required (user)

Request JSON:
```json
{}
```

Success Response (201):
```json
{
  "detail": "STK push sent",
  "checkout_request_id": "string"
}
```

Error Response (400):
```json
{
  "detail": "Missing Idempotency-Key"
}
```

Error Response (400, insufficient stock):
```json
{
  "detail": "Insufficient stock for <product_name>"
}
```

Error Response (400, payment in progress):
```json
{
  "detail": "Payment already in progress"
}
```

**Field Explanations:**
- `checkout_request_id`: Unique identifier for the payment request (from payment provider)
- `detail`: Human-readable status or error message

Validation Rules:
- `Idempotency-Key` header must be present and unique per user/order attempt
- User must be authenticated
- Cart must not be empty
- All items must have sufficient stock

POST /api/v1/payments/daraja/callback/

**Headers:**
- None (public endpoint, called by payment provider)

**Authentication:** None

Request JSON:
```json
{
  "Body": {
    "stkCallback": {
      "MerchantRequestID": "string",
      "CheckoutRequestID": "string",
      "ResultCode": 0,
      "ResultDesc": "string",
      "CallbackMetadata": {
        "Item": [
          {"Name": "MpesaReceiptNumber", "Value": "string"},
          {"Name": "PhoneNumber", "Value": "string"},
          {"Name": "Amount", "Value": 1000}
        ]
      }
    }
  }
}
```

Success Response (200):
```json
{
  "message": "Callback processed successfully."
}
```

Error Response (400):
```json
{
  "error": "Invalid callback format."
}
```

Error Response (404):
```json
{
  "error": "Transaction not found."
}
```

**Field Explanations:**
- `MerchantRequestID`, `CheckoutRequestID`: Payment provider identifiers
- `ResultCode`: 0 for success, nonzero for failure
- `CallbackMetadata`: Payment details

Validation Rules:
- Callback must include valid IDs and structure
- Only unprocessed transactions are accepted (idempotency)
