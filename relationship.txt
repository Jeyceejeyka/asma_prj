


| Relationship        | Defined in | Field         |
| ------------------- | ---------- | ------------- |
| Category → Product  | Product    | ForeignKey    |
| User → Cart         | User       | OneToOneField |
| Cart → CartItem     | CartItem   | ForeignKey    |
| Product → CartItem  | CartItem   | ForeignKey    |
| User → Order        | Order      | ForeignKey    |
| Order → OrderItem   | OrderItem  | ForeignKey    |
| Product → OrderItem | OrderItem  | ForeignKey    |
| Order → Payment     | Payment    | OneToOneField |

==================================
==== Rule you should remember ====
==================================
One-to-many → use ForeignKey on the “many” side
One-to-one → use OneToOneField
Never define relationships on both models
